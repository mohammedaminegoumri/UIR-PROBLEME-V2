# Quick Start Guide - UIR PROBLEMES

Get your platform live in minutes!

## 🚀 Fastest Deployment (5 minutes)

### Option 1: Netlify (Recommended)

1. **Create Netlify Account**
   - Go to [netlify.com](https://netlify.com)
   - Sign up with GitHub, GitLab, or email

2. **Deploy**
   - Click "Add new site" → "Import an existing project"
   - Connect your Git repository
   - Netlify auto-detects settings ✅
   - Click "Deploy site"

3. **Done!**
   - Your site is live at `random-name.netlify.app`
   - Free HTTPS included
   - Automatic deployments on push

4. **Custom Domain (Optional)**
   - Go to "Domain settings"
   - Click "Add custom domain"
   - Follow DNS instructions
   - Suggested: `uirproblemes.com` or `uirproblemes.ma`

**That's it! Your platform is live.**

## 🛠️ Development (Optional)

If you want to customize the platform:

### Local Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev
# Opens at http://localhost:5173

# Build for production
npm run build
```

### Customization Ideas
1. **Change Colors**: Edit Tailwind classes in components
2. **Add Categories**: Update category arrays in components
3. **Modify Limits**: Change character limits in forms
4. **Add Features**: Create new components in `src/components/`

## 📊 Monitor Usage

### Simple Analytics (No Tracking)

Want to see visitor counts without tracking users?

**Add Privacy-Friendly Analytics:**

1. **Plausible** (Recommended)
   - Sign up at [plausible.io](https://plausible.io)
   - Add script tag to `index.html`
   - GDPR compliant, no cookies

2. **Simple Analytics**
   - Visit [simpleanalytics.com](https://simpleanalytics.com)
   - Add script tag
   - Privacy-focused

**Important**: Update Privacy Policy if adding analytics!
