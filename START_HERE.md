## ⚡ Quick Start (30 seconds)

1. **Open terminal in this project folder**

2. **Run this command:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   ```
   http://localhost:5173
   ```

**That's it!** Your platform is now running with full real-time synchronization! 🎉

## 🔧 Troubleshooting

### Server won't start?
```bash
# Make sure port 3001 is free
# Or check if another app is using it
```

### Real-time not working?
- Check browser console (F12)
- Make sure server is running
- Refresh the page

### Need to reset everything?
```bash
# Delete database and restart
rm server/uir_problemes.db
npm run dev
```
